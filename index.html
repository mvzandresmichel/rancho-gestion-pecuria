Transferencia entre dispositivos
📱 Tablet ↔ 📱 Teléfono

Esta versión permite mover una copia completa de tus datos entre dispositivos mediante un archivo JSON. No borra el dispositivo de origen.

En el teléfono: recibe el archivo, abre la aplicación y usa “Importar respaldo”. La copia sustituye los datos actuales del teléfono por los del archivo.

Migración
V6.8 conserva los datos locales. Inicia sesión arriba y usa Subir datos locales a la nube una sola vez para migrar esta copia. Después, los cambios guardados se sincronizan automáticamente.
